This project addresses a common barrier in introductory data science by providing a **zero-setup**, **web-based** environment for students. 
The custom webpage allows users to complete suggested exercises from the influential [*R for Data Science*](https://r4ds.hadley.nz/) textbook immediately, without requiring any local software installation. 
This seamless accessibility ensures all students can quickly begin their data cleaning and analysis practice, providing crucial, timely preparation for their year-long project.
